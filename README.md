# Постановка задачи
Атомы в узлах кристаллической решётки моделируются упругими диполями без затухания. Диполи изотропны: коэффициент жёсткости $k$ одинаков во всех направлениях. Предполагается, что параметры $k$, масса осциллятора $m$ и заряд $e$ являэтся характеристиками химического элемента и не зависят от самого вещества.

В направлении распространения волны $z$ решётка получается трансляцией исходной (реплицирование). В перпедникулярном направлении имеют место периодические граничные условия. Таким образом, вектор напряжённости в падающей волне лежит в плоскости $xy$. Если ось $x$ -- оптическая ось кристалла, то угол $\theta$ между осью $x$ и вектором $\vec{E_0}$ задаёт поляризацию падающей волны. 

Уравнение движения диполя:

$$
m\ddot{\vec{r}} = -k \vec{r} + e \vec{E},
$$

где $\vec{E} = \vec{E}_0 + \sum_i \vec{E}_i$ -- электрическое поле в точке расположения диполя, которое является суммой поля в падающей волне и полей остальных диполей. Суммирование по диполям ведётся следующим образом: в направлении распространения волны учитываются все диполи в кристалле (~1000 ячеек), в строго перпендикулярном -- разумное количество. Поскольку волна падает на бесконечно плоскую поверхность кристалла, значение дипольного момента зависит только от координаты $z$.

\textbf{Важно!} Рассматривается усвновившийся режим (собственные колебания затухли). Следовательно, все дипольные моменты колеблются с частотой падающей волны $\omega$. Это позволяет перейти к работе с комплексными амплитудами. 
# Дипольное излучение

Поле колеблющегося диполя $\vec{d}$:

$$
\vec{E}_\text{дип} = \dfrac{3(\vec{d}(t - r/c)\vec{r})\vec{r}}{r^5} - dfrac{\vec{d}(t - r/c)}{r^3} + \dfrac{3(\dot{\vec{d}}(t - r/c)\vec{r})\vec{r}}{r^4c} - dfrac{\dot{\vec{d}}(t - r/c)}{r^2c} + \dfrac{[\vec{r},[\vec{r},\ddot{\vec{d}}(t - r/c)]]}{r^3c^2}.
$$

Для каждого узла будем хранить три компоненты комплексной амплитуды дипольного момента $d_x,d_y,d_z$ (каждая компонента -- комплексное число). Тогда уравнения движений для диполей можно записать в матричном виде:

$$
M\ddot{q} + \omega_0^2 q = \tau_1 q + \tau_2 \dot{q} + \tau_3\ddot{q} + E_0.
$$

Здесь $q$ -- "обобщённая координата", вектор из $3KN$ компонент комплексных амплитуд дипольных моментов, где $K$ -- число атомов в ячейке, $N$ -- число ячеек. $\tau_1,~\tau_2,~\tau_3$ -- матрицы передачи. В них зашито излучение всех остальных диполей.
