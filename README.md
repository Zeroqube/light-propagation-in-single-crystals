# light-propagation-in-single-crystals
This is a repository for a student research project in computational physics and laboratory practice.

В направлении распространения волны $z$ решётка получается трансляцией исходной (реплицирование). В перпедникулярном направлении имеют место периодические граничные условия. Таким образом, вектор напряжённости в падающей волне лежит в плоскости $xy$. Если ось $x$ -- оптическая ось кристалла, то угол $\theta$ между осью $x$ и вектором $\vec{E}$ задаёт поляризацию падающей волны.
